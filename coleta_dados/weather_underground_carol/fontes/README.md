# Fontes

Esta pasta contém os arquivos responsáveis pela leitura dos dados meteorológicos e pela futura integração com a API do Weather Underground.

* `csv_manual.py`: realiza a leitura dos dados do arquivo CSV consolidado.
* `api_weather_underground.py`: reservado para a implementação da coleta automática pela API, ainda pendente devido à falta de uma chave de acesso.
* `__init__.py`: arquivo de inicialização do pacote Python.
