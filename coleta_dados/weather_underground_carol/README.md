# Dados brutos — Weather Underground

Nesta pasta estão os arquivos CSV baixados manualmente do Weather Underground, referentes à estação IIJU2, de Ijuí (RS), entre os dias 1º e 8 de outubro de 2026. Os arquivos diários foram mantidos como baixados da plataforma. Também há um arquivo consolidado, que reúne os dados desse período em um único CSV.

Os dados incluem temperatura, umidade, vento, pressão atmosférica, precipitação, índice UV e radiação solar.

**Observação:** os arquivos originais foram mantidos sem alterações. A coleta foi feita manualmente, pois ainda não temos uma chave de acesso para utilizar a API do Weather Underground.
